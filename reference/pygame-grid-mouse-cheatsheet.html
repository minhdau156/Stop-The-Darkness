ReferenceGrid & Mouse Picking — Cheat Sheet

Tra nhanh công thức lưới ô + chuột. Chi tiết: Bài 3: Lưới ô và bắt click chuột.

Dữ liệu lưới — tách khỏi hình vẽ

grid = [[0 for _ in range(GRID_COLS)] for _ in range(GRID_ROWS)]
# Truy cập: grid[row][col]  — HÀNG trước, CỘT sau

Chỉ số ô → pixel (để vẽ)

x = col * TILE_SIZE
y = row * TILE_SIZE

Pixel → chỉ số ô (để bắt click)

col = x // TILE_SIZE   # // = chia lấy phần nguyên
row = y // TILE_SIZE

Kiểm tra biên (luôn làm trước khi đọc/ghi grid)

def is_valid(row, col):
    return 0 <= row < GRID_ROWS and 0 <= col < GRID_COLS

Sự kiện chuột vs hàm hỏi vị trí

APIKhi nào kích hoạt
event.type == pygame.MOUSEBUTTONDOWNĐúng một lần, ngay frame chuột được bấm xuống. Toạ độ: event.pos.
event.type == pygame.MOUSEBUTTONUPĐúng một lần, ngay frame chuột được nhả ra.
pygame.mouse.get_pos()Không phải event — gọi được bất kỳ lúc nào, mọi frame, trả về vị trí chuột hiện tại.

Vẽ viền thay vì tô đặc

pygame.draw.rect(screen, color, rect)              # tô đặc (mặc định)
pygame.draw.rect(screen, color, rect, width=2)      # chỉ vẽ viền dày 2px
Nguồn: pygame.event · pygame.mouse · pygame.draw
