ReferenceGame State Patterns — Cheat Sheet

Tra nhanh 4 pattern dùng xuyên suốt game xây dựng của bạn. Chi tiết từng pattern nằm ở Bài 4, Bài 5, Bài 6, Bài 7.

1. Thông báo tạm thời (temporary message) — Bài 4

message, message_timer = "", 0

# Update, mỗi frame:
if message_timer > 0:
    message_timer -= 1

# Gây ra thông báo:
message, message_timer = "Không đủ tài nguyên", 90   # ~1.5s ở 60 FPS

# Draw:
if message_timer > 0:
    screen.blit(font.render(message, True, (255,200,80)), (20, 60))

2. Thu nhập theo nhịp (income tick) — Bài 4

frame_counter = 0
TICK_FRAMES = 60   # ~1 giây ở 60 FPS

frame_counter += 1
if frame_counter >= TICK_FRAMES:
    frame_counter = 0
    resource += INCOME_PER_TICK

3. Nút bấm (button) — Bài 5 & 7

btn = pygame.Rect(x, y, w, h)

# Vẽ:
pygame.draw.rect(screen, color, btn)
text_rect = label_surface.get_rect(center=btn.center)
screen.blit(label_surface, text_rect)

# Bắt click:
if event.type == pygame.MOUSEBUTTONDOWN and btn.collidepoint(event.pos):
    ...

4. Thứ tự kiểm tra "lý do không cho phép" — Bài 4, 6

if <ô đã xây>:
    message = "..."
elif :
    message = "..."
elif :
    message = "..."
else:
       # chỉ chạy khi mọi điều kiện chặn đều KHÔNG đúng

Luôn kiểm tra từng lý do không cho phép trước; hành động thật sự nằm ở else cuối cùng. Không trừ tài nguyên/đổi state trước rồi "sửa lại" sau.

5. 4-lân cận trên lưới (grid neighbors) — Bài 6

def get_neighbors(row, col):
    candidates = [(row-1,col), (row+1,col), (row,col-1), (row,col+1)]
    return [(r,c) for r,c in candidates if is_valid(r,c)]

6. Máy trạng thái (state machine) — Bài 7

game_state = "START"   # hoặc "PLAYING", "WON"

if game_state == "START":
    ...
elif game_state == "PLAYING":
    ...
elif game_state == "WON":
    ...

Quy tắc: mọi vẽ và xử lý sự kiện của một màn hình phải nằm trong đúng nhánh game_state tương ứng — không có ngoại lệ "chạy ở mọi state".

7. Reset state đầy đủ — Bài 7

def reset_game():
    global grid, resource, frame_counter, message, message_timer
    grid = [[0]*GRID_COLS for _ in range(GRID_ROWS)]
    resource = 20
    frame_counter = 0
    message, message_timer = "", 0

Checklist: mọi biến state toàn cục được thêm ở Bài 3-6 phải xuất hiện trong cả khai báo global lẫn phần gán lại giá trị khởi điểm.
