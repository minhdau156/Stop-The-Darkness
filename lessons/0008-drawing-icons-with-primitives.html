Pygame · Bài 8 — nâng cấp hình ảnh (tuỳ chọn)Vẽ icon Cây & Đá bằng hình khối cơ bản

Từ Bài 3 tới giờ, mỗi ô trên lưới chỉ là một hình chữ nhật tô màu phẳng. Bài này nâng cấp hình ảnh đó thành những icon đơn giản — một cây và một tảng đá — mà không cần tải bất kỳ file ảnh nào. Đây là bài tuỳ chọn (polish), đúng như gợi ý ở cuối Bài 7: làm bản lõi chạy được trước, phần này chỉ để game trông "có hồn" hơn nếu bạn còn thời gian trước deadline.

Vì sao không dùng ảnh PNG tải trên mạng Dùng hình ảnh thật (pygame.image.load) là một hướng đi hợp lệ, nhưng nó tốn thời gian tìm/chỉnh file đúng kích thước, và dễ dính vấn đề bản quyền nếu bạn lấy ảnh có sẵn trên mạng rồi nộp bài. Vẽ icon bằng hình khối nguyên thuỷ (pygame.draw) thì luôn là của riêng bạn, không phụ thuộc file ngoài, và đủ đơn giản để chỉnh sửa ngay trong code bất cứ lúc nào.

Mô hình tư duy: icon = nhiều hình khối ghép lại, vẽ theo đúng thứ tự lớp

Một icon "phức tạp" hơn hình chữ nhật chỉ đơn giản là nhiều lệnh pygame.draw gọi liên tiếp, chồng lên nhau theo thứ tự — y hệt cách bạn xếp giấy màu lên nhau để làm thủ công. Hình vẽ sau sẽ nằm đè lên hình vẽ trước, vì Surface không có khái niệm "lớp" (layer) — nó chỉ nhớ pixel nào được vẽ sau cùng.

Hình khối mới: pygame.draw.polygon

Bạn đã biết rect và circle. Để vẽ tảng đá (hình dạng không đều), cần thêm một hàm mới: pygame.draw.polygon(surface, color, points, width=0) — vẽ một đa giác nối liền các điểm trong danh sách points theo đúng thứ tự, tự động nối điểm cuối về điểm đầu. 

points = [(100, 150), (120, 120), (150, 130), (160, 160), (120, 170)]
pygame.draw.polygon(screen, (130, 130, 130), points)          # tô đặc (mặc định)
pygame.draw.polygon(screen, (90, 90, 90), points, width=2)    # chỉ viền
Lưu ý về width với polygon Giống draw.rect, width=0 (mặc định) tô đặc, width > 0 chỉ vẽ viền. Nhưng khác với rect: với polygon, viền vẽ bằng width > 1 có thể lan ra ngoài biên gốc của hình một chút — nếu thấy viền "phình to" hơn hình tô đặc bên dưới, đây chính là lý do, không phải bạn tính sai toạ độ.

Vẽ Cây (Tree): thân + tán lá

def draw_tree(screen, x, y, size=40):
    # (x, y) là điểm GỐC CÂY — chân cây chạm đất, không phải tâm hình
    trunk_w, trunk_h = size // 4, size // 2
    trunk_rect = (x - trunk_w // 2, y - trunk_h, trunk_w, trunk_h)
    pygame.draw.rect(screen, (90, 60, 40), trunk_rect)          # 1. thân cây — vẽ TRƯỚC

    canopy_center = (x, y - trunk_h)
    canopy_radius = size // 2
    pygame.draw.circle(screen, (40, 110, 50), canopy_center, canopy_radius)  # 2. tán lá — vẽ SAU, đè lên đỉnh thân

Để ý thứ tự: thân cây vẽ trước, tán lá vẽ sau. Nếu đảo ngược, phần đỉnh thân cây (đáng lẽ bị tán lá che) sẽ lòi ra đè lên tán lá, trông sai hẳn. Đây chính là "thứ tự lớp" nhắc ở phần Mô hình tư duy, áp dụng ngay vào ví dụ đầu tiên.

Vẽ Đá (Stone): một đa giác bất quy tắc

def draw_stone(screen, x, y, size=40):
    # (x, y) là điểm GIỮA ĐÁY tảng đá
    points = [
        (x - size // 2, y),
        (x - size // 3, y - size // 3),
        (x,              y - size // 2),
        (x + size // 3,  y - size // 3),
        (x + size // 2,  y),
    ]
    pygame.draw.polygon(screen, (130, 130, 130), points)        # 1. tô đặc màu xám
    pygame.draw.polygon(screen, (90, 90, 90), points, width=2)  # 2. viền sẫm hơn, đè lên mép

5 điểm trong points đi theo thứ tự từ trái sang phải, nhô dần lên rồi hạ xuống — giống hình một mái vòm gồ ghề. Thử tự vẽ 5 điểm này ra giấy trước khi gõ code là cách tốt nhất để không bị rối thứ tự.

Pitfall — điểm polygon vẽ sai thứ tự Nếu các điểm trong points không theo đúng thứ tự đi quanh hình (ví dụ nhảy cóc qua lại), các cạnh nối sẽ bắt chéo nhau, cho ra hình dạng méo mó kiểu "con bướm" thay vì một khối liền mạch. Luôn liệt kê điểm theo đúng một chiều duy nhất quanh hình (ví dụ toàn bộ theo chiều kim đồng hồ, hoặc toàn bộ ngược chiều kim đồng hồ).

Gắn icon vào lưới (nối lại Bài 3 & Bài 5)

def draw_grid(screen, grid):
    for row in range(GRID_ROWS):
        for col in range(GRID_COLS):
            x, y = col * TILE_SIZE, row * TILE_SIZE
            rect = (x, y, TILE_SIZE, TILE_SIZE)
            cell = grid[row][col]

            base_color = (50, 70, 50) if cell == 0 else (40, 55, 40)
            pygame.draw.rect(screen, base_color, rect)           # nền ô — luôn vẽ trước icon
            pygame.draw.rect(screen, (20, 20, 20), rect, width=2)

            center_x = x + TILE_SIZE // 2
            bottom_y = y + TILE_SIZE - 8   # chừa 8px lề dưới cho icon không dính sát viền ô

            if cell == 1:       # Trạm Gỗ -> vẽ Cây
                draw_tree(screen, center_x, bottom_y, size=TILE_SIZE - 20)
            elif cell == 2:     # Tháp Canh -> vẽ Đá
                draw_stone(screen, center_x, bottom_y, size=TILE_SIZE - 20)

Đây chính là lý do cả draw_tree và draw_stone đều nhận (x, y) là điểm đáy, không phải tâm: khi gắn vào lưới, bạn luôn muốn icon "đứng" trên nền ô, không lơ lửng giữa ô. Quy ước đáy-làm-gốc là cách làm chuẩn cho mọi icon đối tượng đứng trên mặt đất trong game 2D nhìn từ trên xuống hoặc chéo góc.

Những lỗi thường gặp

Pitfall #1 — vẽ icon trước nền ô Nếu lệnh vẽ nền ô (pygame.draw.rect(screen, base_color, rect)) nằm sau lệnh gọi draw_tree/draw_stone, nền ô sẽ đè mất icon vừa vẽ — màn hình chỉ còn lại ô màu phẳng, y hệt trước khi làm bài này.
Pitfall #2 — lẫn lộn "tâm" và "đáy" khi tính toạ độ Hàm draw_tree coi (x, y) là đáy (chân cây), nhưng canopy_center bên trong hàm lại là một tâm hình tròn khác, tính dựa trên đáy đó. Nếu bạn quen tay truyền toạ độ tâm ô (như get_rect(center=...) ở Bài 2) vào thẳng draw_tree, cây sẽ vẽ lệch nửa ô lên trên so với bạn mong đợi. Luôn kiểm tra: hàm đang cần toạ độ tâm hay toạ độ đáy?
Pitfall #3 — size quá lớn so với TILE_SIZE Nếu truyền size bằng đúng TILE_SIZE (không trừ bớt), icon sẽ tràn ra ngoài viền ô, chồng lên ô bên cạnh. Luôn để icon nhỏ hơn ô một chút (ví dụ TILE_SIZE - 20 như ví dụ trên) để còn khoảng trống nhìn rõ viền từng ô.

Thử tự tay làm

  1. Viết draw_tree và draw_stone, gọi thử độc lập (không cần lưới) tại vài toạ độ cố định để xem hình dạng trước.
  2. Ghép vào draw_grid theo đúng loại công trình (Trạm Gỗ → Cây, Tháp Canh → Đá), thay cho màu phẳng cũ.
  3. Chạy game đầy đủ (từ Bài 7), xây cả hai loại công trình, xác nhận icon hiện đúng loại, đúng vị trí, không tràn ra ngoài ô.
  4. Nâng cao: thêm một icon thứ ba (tự thiết kế hình dạng riêng — ví dụ một bụi cây nhỏ bằng 2-3 hình tròn chồng nhau) cho loại công trình bạn tự thêm ở Bài 5 nếu có.

Kiểm tra lại hiểu biết

Trong draw_tree, vì sao lệnh vẽ thân cây (trunk) phải nằm TRƯỚC lệnh vẽ tán lá (canopy)?

pygame.draw.polygon(screen, color, points, width=2) khác gì so với width=0 (mặc định)?

Vì sao draw_tree(screen, x, y, size) coi (x, y) là điểm ĐÁY (chân cây) thay vì tâm?

Nếu icon vẽ ra bị lệch vị trí, méo hình, hoặc đè sai lớp — cứ dán hàm draw_tree/draw_stone của bạn lên hỏi mình, kèm mô tả "nó đang trông như thế nào" để dễ hình dung.
